# проверка версии 0.2.2

- 22 проверки frontend: поиск, частота, параметры, отказ от неподдерживаемых материалов и одновременных обновлений.
- 4 проверки rust: запрет запуска произвольных команд, повреждённый каталог и геометрия углов при разном dpi и высоте окна.
- в настоящем webview проверены три материала и переключение радиуса 0 / 16 / 40.
- глобальная клавиша зарегистрирована как alt + пробел после освобождения сочетания fluent search.
- github actions проверяет frontend, типы, rust-тесты и форматирование перед выпуском.
- нативная проверка формы окна: угловая точка исключена из региона, внутренняя включена, клиентская область начинается от 0,0. наличие флага caption само по себе не используется как доказательство отсутствия видимой рамки.
- исправление 0.2.2: одной проверки региона оказалось недостаточно. windows восстанавливала неклиентскую область после показа и меняла обрезку при изменении размера. теперь обработчик рамки сохраняет клиентскую область от 0,0, повторно применяет форму и учитывает dpi. css-скругление совпадает с формой нативного окна.
- `npm run test:desktop` проверяет оба окна после resize/show/theme, а не только сохранённый радиус. значения оформления передаются в событии напрямую между окнами.
- реальная проверка обновления: локальная сборка с номером 0.2.0 запущена скрыто, сама скачала подписанный выпуск 0.2.1 из публичного github releases, установила его для текущего пользователя и перезапустилась из установленной папки. ручного запуска установщика не было.

системный acrylic не предоставляет регулировку радиуса; настройки отдельно управляют материалом, плотностью заливки и геометрией углов.
