# проверка версии 0.2.1

- 22 проверки frontend: поиск, частота, параметры, отказ от неподдерживаемых материалов и одновременных обновлений.
- 2 проверки rust: запрет запуска произвольных команд и обработка повреждённого каталога.
- в настоящем webview проверены три материала и переключение радиуса 0 / 16 / 40.
- глобальная клавиша зарегистрирована как alt + пробел после освобождения сочетания fluent search.
- github actions проверяет frontend, типы, rust-тесты и форматирование перед выпуском.
- нативная проверка формы окна: угловая точка исключена из региона, внутренняя включена, флаги старой рамки отсутствуют.
- реальная проверка обновления: локальная сборка с номером 0.2.0 запущена скрыто, сама скачала подписанный выпуск 0.2.1 из публичного github releases, установила его для текущего пользователя и перезапустилась из установленной папки. ручного запуска установщика не было.

системный acrylic не предоставляет регулировку радиуса; настройки отдельно управляют материалом, плотностью заливки и геометрией углов.
