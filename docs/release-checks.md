# проверка версии 0.2.3

- 22 frontend-проверки поиска, частоты, параметров и безопасного обновления; 4 rust-проверки каталога и dpi-геометрии.
- `npm run test:desktop` проверяет передачу параметров между окнами, клиентскую область от 0,0, resize/show/theme и повторное создание настроек. исходные параметры пользователя восстанавливаются после проверки.
- вместо прежней бинарной обрезки HRGN фон и тонировка рисуются windows composition и обрезаются общим сглаженным контуром. отсутствие жёсткой обрезки проверяется отдельно.
- время жизни compositor привязано к окну; настройки и поиск обновляют фон при смене фокуса.
- окна сверялись визуально после активации: снимок перекрытого окна может показывать перекрывающий его экран и не считается доказательством корректного внешнего вида.
- проверка системного входа и других видеодрайверов не проводилась.
