# kpax search

личный лаунчер программ для windows. компактная строка поиска и выпадающий список: только иконки и названия. тема следует windows, матовый фон создаётся системным acrylic. окно имеет одну системную кромку без дополнительной нарисованной рамки.

## запуск

скачать текущую версию: [github releases](https://github.com/darkkpax/kpaxsearch/releases/latest). пакет устанавливается для текущего пользователя и поддерживает подписанные обновления. `release/kpaxsearch.exe` — локальная сборка для проверки.

**alt + пробел** открывает поиск. если сочетание занято, используется **ctrl + alt + пробел**. действующее сочетание находится в подсказке трея и настройках. повторный запуск exe открывает уже работающий экземпляр.

стрелки выбирают программу, enter запускает, esc скрывает окно, ctrl + k выделяет строку. поиск понимает сокращения (`vsc`), пропущенные буквы и неверную русскую/английскую раскладку. при пустой строке сначала идут программы с наибольшим числом запусков через этот лаунчер, затем последние использованные. история не подменяется выдуманными данными об использовании windows.

## настройки

щелчок по значку в трее открывает отдельное окно настроек. правая кнопка открывает меню поиска, настроек и выхода.

настройки применяются сразу и сохраняются локально:

- матовое стекло — включить системное размытие или непрозрачный фон;
- плотность стекла — прозрачность заливки поверх размытого фона;
- материал — матовый акрил, мягкое стекло или слюда (оттенок обоев);
- округлость окна — от 0 до 40 логических пикселей, включая настоящую форму нативного окна;
- число видимых программ — от 4 до 10; список прокручивается, высота окна уменьшается при небольшом числе результатов;
- обновить программы — заново получить каталог windows.

радиус системного acrylic задаёт windows. ползунок плотности не выдаётся за регулировку этого радиуса. слюда использует оттенок обоев, а не размытие других окон. для эффекта нужны включённые «эффекты прозрачности» windows. при недоступности материала используется непрозрачный фон. ручного выбора темы нет: изменения темы windows подхватываются автоматически. системное уменьшение анимаций учитывается.

## автозапуск и обновления

при первом запуске обычной сборки включается автозапуск для текущего пользователя; его можно выключить в настройках. при входе в windows приложение запускается скрыто в трее. через пять секунд после запуска оно проверяет github releases, скачивает более новую версию, проверяет цифровую подпись и устанавливает её без вопросов. установка выполняется для текущего пользователя без повышения прав. при сетевой ошибке продолжает работать установленная версия. в настройках есть ручная проверка и установка.

обновления используют tauri updater и отдельную ключевую пару. приватный ключ не попадает в репозиторий: он находится в защищённых github actions secrets и в локальной резервной копии вне проекта. действия пользователя в поиске не отправляются на сервер; сетевые запросы используются для проверки версии и загрузки пакета.

публикация следующего выпуска: обновить версии в `package.json`, `src-tauri/Cargo.toml` и `src-tauri/tauri.conf.json`, обновить lock-файлы, отправить коммит и тег `v<версия>`. github actions запускает проверки, собирает подписанный пакет и публикует манифест обновлений `latest.json`.

## каталог

обнаруживаются программы из меню «пуск», в том числе microsoft store. документы, справка, веб-ссылки и деинсталляторы отфильтрованы. portable-программам нужен ярлык в `%APPDATA%/Microsoft/Windows/Start Menu/Programs`. каталог и иконки сохраняются в `%LOCALAPPDATA%/com.kpax.search/programs.json`, поиск работает в памяти без сетевых запросов.

при первом запуске сбор занимает несколько секунд. далее кэш показывается сразу и обновляется в фоне. частота учитывает успешные запуски через поиск; прежние недавние запуски используются при одинаковой частоте. параметры и статистика хранятся локально.

## разработка

tauri 2 + rust + typescript, без frontend-фреймворка. node.js 22.12+, rust/msvc и webview2 runtime. проверено на windows 11 x64.

```powershell
npm ci
npm run tauri dev
```

```powershell
npm test
npm run build
cargo test --manifest-path src-tauri/Cargo.toml
cargo fmt --manifest-path src-tauri/Cargo.toml -- --check
npm run tauri build -- --no-bundle
```

exe создаётся в `src-tauri/target/release/`. для подписанного пакета `npm run tauri build` нужны переменные `TAURI_SIGNING_PRIVATE_KEY` и `TAURI_SIGNING_PRIVATE_KEY_PASSWORD`. перед заменой exe заверши приложение через трей. измерение поиска без отрисовки и запуска программ:

```powershell
node scripts/benchmark.mjs "$env:LOCALAPPDATA/com.kpax.search/programs.json"
```

nunito sans взят из локального edithub; лицензия sil open font license находится в `src/assets/fonts/`. fluent search — функциональный ориентир, его исходный код здесь не используется.
